# Fotos das subclasses

Adicione as fotos nesta pasta usando exatamente o nome gerado no campo `image` de cada registro em `src/App.jsx`.

Exemplos:

- `barbaro-caminho-do-furioso.jpg`
- `bardo-colegio-do-conhecimento.jpg`
- `mago-escola-de-evocacao.jpg`

As imagens devem ser JPG. Se uma foto ainda não existir, o app usa `public/images/folhas.png` como imagem reserva.
